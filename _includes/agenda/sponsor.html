{%- comment -%} The sponsor callout at the top of an event's agenda page — who paid for the room, and why they wanted to. include.slug the event's slug (required) Authored per event in _data/events.yml, where the rest of the event's wording already lives. Never in _data/agenda.yml: every `agenda.php export` rewrites that file, and a sponsor is wording, not schedule. A list, so an event can carry one sponsor or several. Each entry: name: the company, as it should be written. Required — an entry without one is skipped, since there would be nothing to show. url: optional; their site. With one, the logo and the name link to it. Without one, both render as plain text. logo: optional; a site path or an https:// URL. Left out, the callout looks for a file named after them in assets/img/sponsors/ — see agenda/sponsor-logo.html — and with neither, shows the name on its own. blurb: optional; a sentence or two on why they are sponsoring. Keep it under 300 characters — _plugins/agenda.rb warns at build time if it runs longer, and nothing is truncated, so an overlong one just makes the callout tall. HTML is allowed, as it is elsewhere in _data/events.yml. An event with no `sponsors:` key renders nothing at all. {%- endcomment -%} {%- assign sponsors = "" -%} {%- for event in site.data.events -%} {%- if event.slug == include.slug and event.sponsors -%} {%- assign sponsors = event.sponsors -%} {%- break -%} {%- endif -%} {%- endfor -%} {%- if sponsors != "" and sponsors.size > 0 -%} {%- comment -%} Does anyone on this bill have a logo?
